# Этерна v0.7.2.1 — единая резервная копия кампании

## Обновление
1. В v0.7.2 выгрузите общую базу JSON. Сохраните и прежний ZIP.
2. Распакуйте архив v0.7.2.1 и замените все файлы в том же репозитории GitHub Pages. Не меняйте адрес сайта: localStorage привязан к origin.
3. После публикации откройте сайт онлайн и дождитесь обновления автономного кэша. Проверьте версию, NPC, локации, города, объекты и ссылки. Не очищайте данные сайта до резервного копирования.
4. Если нужен откат, используйте прежний ZIP и прежнюю резервную копию: старые версии не понимают городские ссылки и категорию объектов. Не перезаписывайте единственную копию базы.

## Объекты
60 стандартных типов, 12 категорий, 300 готовых названий, 200 элементов и 60 шаблонов; 600 описаний, 600 особенностей, 540 весов районов и 10 резервных строк. Категория, тип, район и три текстовых поля генерируются отдельно или одним действием. Закрепление действует в текущем редакторе; заметки не генерируются. Категория «Другое»/свой тип вводится вручную; в известных категориях тоже доступен произвольный тип. Совмещённые районы с неструктурированным описанием не угадываются, выбираются вручную; отсутствующие/неописанные зоны исключены из автоматического выбора. Если нет подходящей зоны, район пустой. Сохраняйте объект, затем город. Нет массовой генерации.

## NPC
Одно основное место: загородная локация, город или объект. Связь хранится в meta.locationId либо meta.cityId + необязательный meta.objectId. Старый текст meta.location сохраняется. Город определяется по ID; NPC показываются в общей картотеке по городу, название объекта видно в карточке. Связи можно менять в редакторе NPC и сохранённых локациях/городах/объектах. Для новых объектов сначала сохраните город. Изменение связи действует сразу. Удаление объекта после сохранения города переводит связанных NPC на уровень города, удаление города оставляет их без структурированной ссылки, сохраняя старый текст места либо добавляя прежнее название, если текст пуст. Подтверждение обязательно. При ошибке записи города предусмотрена попытка отката записи NPC.

## Резервные копии
В общем блоке «База кампании» доступны две кнопки: «Сохранить всю базу (JSON)» и «Загрузить базу (JSON)». Прежние дублирующие кнопки убраны. Сначала сохраните и закройте редактор карточки. Экспорт содержит только сохранённые записи и их ID-связи; импорт объединяет записи, не заменяет конфликтующие ID. Старые NPC-only файлы поддерживаются. При повреждённой базе отдельные кнопки аварийной выгрузки остаются в соответствующих картотеках. Сохранение карточек в localStorage не менялось.
Ключи localStorage прежние. Общий JSON содержит characters, locations, cities; прежние форматы читаются. Не найденные ссылки при импорте не удаляются автоматически, число показывается в подтверждении. Конфликтующие ID не перезаписываются. При переносе используйте общую базу, а не только NPC. Нет синхронизации устройств.

Реальный HTTPS, service worker и iPad не проверены. Названия стилизованные; веса и новые типы требуют игрового теста.

## v0.8 — журнал, квесты, цепочки (27.11.2026)

Шесть разделов. Журнал сессий: номер, дата, название, содержание, подготовка к следующей сессии; поиск и редактирование. Квесты: название, цепочка (необязательно), цель, прогресс, поворот, статус, переходы, связи с несколькими NPC, городами и загородными локациями. Связи хранятся только в квесте по ID; обратные списки вычисляются при открытии карточек. Никаких новых генераторов. Квесты и цепочки создаются вручную. Для перехода сначала сохраните оба квеста, затем выберите следующий в карточке предыдущего. Один безусловный переход для текущего результата (выполнен/провален) открывает следующий автоматически. Условный переход или несколько альтернатив требуют ручного выбора после сохранения результата (откройте квест снова, отметьте нужные переходы, сохраните). Любой удовлетворённый вход открывает подготовленный квест (логика ИЛИ); активация вручную. Можно выбрать несколько переходов. Активные/завершённые квесты не сбрасываются при изменении предшественника. Циклы отклоняются. Удаление квеста очищает входящие переходы; цепочка удаляется только пустой. Удаление NPC/города/локации сохраняет ссылку квеста как недоступную, её можно отвязать вручную; квесты не удаляются. Журнал не связан с картотеками.

JSON v0.8 содержит characters, locations, cities, sessions, chains, quests. Старые файлы импортируются; новые разделы остаются пустыми, если их нет в файле. Конфликты ID не перезаписываются. Перед импортом показывается число недоступных ссылок. Экспорт только сохранённых записей; закройте редакторы. Старые версии не поддерживают новые разделы, поэтому сохраняйте оригинальную копию до обновления. Не храните JSON кампании в публичном GitHub-репозитории.

### Параллельный тест GitHub Pages

Оставьте стабильную версию в основном репозитории и создайте отдельный репозиторий с **точным именем `eterna-test`**. Распакуйте ZIP и загрузите содержимое в корень ветки main нового репозитория. Settings → Pages → Deploy from a branch → main → /(root) → Save. При пути /eterna-test/ приложение включает тестовый режим, показывает предупреждение и использует префикс `eterna-test:` для всех шести ключей localStorage. Стабильная база не читается и не перезаписывается. Тестовая база первоначально пуста; загрузите копию JSON через интерфейс. При другом имени репозитория изоляция не включается. При обычном обновлении основного сайта прежние ключи сохранены. Разные ветки одного репозитория сами по себе не создают отдельный сайт. Старый v0.7.1 ZIP не удаляйте; если требуется сохранение именно этого кода в Git, создайте ветку stable-v0.7.1 от соответствующего коммита либо загрузите старый архив в отдельную ветку. Не переключайте Pages основного репозитория на тестовую ветку для параллельной работы.

Проверки: Chromium 390 px с имитацией localStorage — предыдущие картотеки, полный цикл JSON, старый NPC-only формат, журнал, создание цепочки, автоматическое открытие, выбор ветки, отказ циклической связи, переходы из квеста к NPC/городу/локации и назад, полный экспорт/импорт. Отдельный тест с имитацией пути /eterna-test/ и localStorage подтвердил раздельные ключи и запись NPC и сессий; навигация на реальный localhost заблокирована средой тестирования. Реальный HTTPS, GitHub Pages, Safari/iPad и service worker новой версии не проверены.
