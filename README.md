# Этерна — генератор NPC v0.1

Первая версия: идентификация. Статическое PWA, без серверной части, API-ключей или внешних библиотек.

## GitHub Pages
1. Создайте репозиторий `eterna-npc` (публичный, если используете бесплатный GitHub Pages; данные в таком репозитории доступны всем).
2. Распакуйте архив и загрузите его содержимое в корень ветки `main`, включая `.nojekyll` (если скрытый файл не виден, создайте его вручную).
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → main → /(root) → Save.
4. Откройте адрес сайта, который покажет GitHub. На iPad в Safari нажмите «Поделиться» → «На экран Домой» → «Открывать как веб-приложение» (если доступно) → «Добавить».
5. Первый запуск — с сетью. Дождитесь сообщения о готовности автономного режима. Проверьте запуск без сети. Хранилище браузера может очищаться, поэтому экспортируйте архив NPC регулярно.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Логика
- Равновероятный выбор 9 рас, затем независимо пола 50/50; фильтры фиксируют соответствующие параметры.
- Имя выбирается из подходящей группы, фамилия — из таблицы соответствующей расы. Все строки равновероятны; повторения из Excel сохранены.
- 30 занятий, три исходных набора весов. Нулевые веса исключены.
- Архив хранится в localStorage конкретного браузера; экспорт JSON — резервная копия, обратный импорт пока не предусмотрен.

## Файлы
`data.js` — данные Excel (12 853 имени, 4 777 фамилий, 30 занятий); `engine.js` — независимые функции генерации; `app.js` — интерфейс и архив; `index.html` и `style.css` — разметка и оформление; `manifest.webmanifest`, `sw.js`, PNG — установка и кэширование PWA.

## Обновления
При изменении данных или кода меняйте версию CACHE в sw.js, чтобы установленное приложение обновило кэш. В следующих версиях можно добавить отдельные модули личности и внешности. Встроенного импорта Excel пока нет.

## Проверка
Данные сопоставлены с каждой исходной строкой Excel. Проверены 180 000 случайных генераций и 54 комбинации расы, пола и контекста. Синтаксис JavaScript проверен Node.js. Браузерная проверка локального HTTP заблокирована средой; установка, копирование, локальный архив и автономный запуск требуют проверки на реальном iPad. Сайт ещё не опубликован.
