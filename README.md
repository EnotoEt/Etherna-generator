# Этерна — инструментарий мастера v0.6.1

Обновление PWA v0.6: упрощён выбор типа и автоматизирован выбор языкового профиля. Все данные и ключи хранения сохранены.

## Установка обновления

1. В v0.6 экспортируйте общую базу JSON и сохраните его вне приложения.
2. Распакуйте ZIP. Загрузите все файлы в корень прежнего репозитория GitHub Pages с заменой старых (включая новые location-data.js, location-engine.js, location-ui.js и .nojekyll). Не меняйте адрес сайта.
3. После публикации закройте и откройте PWA с интернетом. Проверьте v0.6.1, три вкладки и наличие прежних NPC.
4. После загрузки новой версии проверьте автономный режим. Не очищайте данные сайта и не удаляйте приложение без резервной копии.

## Локации

Вкладка «Локации» — картотека, а не отдельный случайный генератор. Нажмите «+ Новая локация», выберите тип из выпадающего списка 29 типов либо «Другое» и введите собственный тип (универсальные резервные таблицы). Название и тип обязательны. Выберите культуру для генерации названия; для людей при каждой генерации названия автоматически и равновероятно выбирается чешский, польский либо словенский профиль. Остальные культуры используют свой профиль автоматически. Выбор профиля скрыт; уже сохранённые названия не изменяются. В названии используются 50% смысловых, 30% фонетических и 20% фамильных вариантов из Excel v0.6.1. Составные названия стилизованы, не гарантированно правильны лингвистически. Исходная форма и ассоциации показаны под названием, если известны. При ручной правке названия эти сведения очищаются.

«Заполнить пустые поля» сохраняет введённый текст. «Перегенерировать незакреплённые» требует подтверждения и заменяет только восемь генерируемых полей, кроме закреплённых. У каждого поля есть отдельная кнопка ↻ и фиксация. Фиксация действует в текущем редакторе. Без культуры имя не генерируется, но остальные поля заполняются. Тип влияет на описания; культура влияет только на название. Среда — ручное поле. В 65% случаев явный результат «Нет отдельной проблемы или тайны» сохраняется как заполненное поле.

Родительская локация — строка сортировки (папка); отдельной иерархии, вложенных карточек и городского генератора нет. Внутренняя структура, метки и заметки — свободный текст. Картотека поддерживает поиск, фильтры по папке, типу, культуре и избранному. Сохранение обновляет карточку по ID. Для удаления необходимо сначала отвязать связанных персонажей.

## Связи с NPC

Сохраните локацию, затем выберите существующего NPC в блоке «Связанные NPC» и нажмите «Привязать». Можно открыть карточку NPC или отвязать его. В редакторе NPC также есть выпадающий список «Связанная карточка локации». У NPC одна связанная локация, а у локации может быть много NPC. Прежнее текстовое поле «Локация» не изменяется автоматически. Группировка NPC по связанному месту обновляется при его переименовании. Одинаковые названия не приводят к автоматической привязке. При переносе связи с другой локации требуется подтверждение. Привязка и отвязка сохраняются сразу, независимо от несохранённых правок карточки места.

## Резервные копии

Во вкладке «Локации» используйте «Экспорт общей базы JSON» (NPC и локации с ID и связями). Обратный импорт объединяет записи, не заменяет целиком архив; прежний NPC JSON тоже поддерживается. Совпадения и конфликты ID пропускаются, а недоступные ссылки остаются в данных и показываются в редакторе NPC. Перед записью валидируются оба массива и показывается сводка. При ошибке записи NPC после записи локаций выполняется попытка отката локаций; при ошибке отката приложение сообщает об этом. Общий импорт не является облачной синхронизацией. Ограничения: 20 МБ файла, 20 000 записей на тип. В прежней вкладке NPC экспорт/импорт предназначены только для персонажей; общий файл импортируйте во вкладке «Локации».

Локальное хранение: прежний `eterna-npc-archive-v1` и новый `eterna-locations-v1`. Старые текстовые локации и записи NPC остаются. При повреждении одной картотеки общий импорт/экспорт блокируется; исходные данные можно выгрузить в соответствующем разделе. Не очищайте данные сайта без копии.
