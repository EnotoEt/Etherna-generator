# Этерна — инструментарий мастера v0.5

Статическое PWA для iPad и браузера. Четыре модуля генератора v0.4 сохранены; новая отдельная картотека NPC.

## Обновление с v0.4

1. Экспортируйте архив JSON из старой версии. Сохраните его вне PWA (например, в «Файлы» на iPad).
2. Распакуйте ZIP и загрузите **все файлы** в корень существующего GitHub-репозитория, заменив старые. Включите новый archive.js и скрытый .nojekyll. Адрес и путь GitHub Pages не меняйте.
3. После успешной публикации откройте прежнее приложение с интернетом. Полностью закройте и снова откройте PWA, если ещё видна старая версия. Проверьте номер v0.5.
4. Проверьте картотеку, количество прежних NPC и автономный запуск. Не очищайте данные сайта и не удаляйте PWA до резервного копирования.

## Картотека

- Вкладки «Генератор» и «Картотека NPC». Персонажи группируются только по локациям; пустая локация — «Нераспределённые». Кампания — дополнительное текстовое поле, не папка.
- Поиск по имени, фамилии, расе, занятию, заметкам, меткам, кампании и другим полям. Фильтры: локация, значимость, состояние, отношение, избранное. Избранное внутри каждой группы выше остальных.
- Быстрое сохранение из генератора не требует метаданных. Откройте «Карточка» для редактирования всех полей. «В генератор» загружает NPC для перегенерации отдельных модулей; «Сохранить изменения» обновляет ту же запись, «Сохранить как нового» создаёт отдельную. Полная генерация всегда начинает нового NPC.
- «+ Новый NPC» позволяет создать карточку вручную без случайной генерации. Имя, раса, пол и контекст обязательны (последние три имеют начальные значения). Фамилия, занятие, метаданные необязательны. Каждый блок настроения, внешности или личности может оставаться пустым либо заполняться целиком. При ручной смене расы проверьте внешность самостоятельно. Пропущенные блоки можно добавить через генератор.
- Дополнительные поля: кампания, локация, значимость, состояние, отношение, метки (свободный текст, например через запятую), заметки, избранное. Локации и кампании вводятся вручную с предложениями уже использованных значений. Никакой иерархии кампаний.

## Хранение и перенос

Ключ localStorage не изменён (`eterna-npc-archive-v1`). Старые карточки получают ID и пустые метаданные; блоки, которые раньше отсутствовали, не генерируются при миграции. Старые дубликаты не удаляются автоматически. Запись производится в локальное хранилище; при ошибке сохранение не считается успешным. Если прежние данные не читаются, приложение блокирует перезапись и позволяет скачать исходный JSON для восстановления.

Экспорт JSON содержит все карточки, их ID и метаданные. Импорт принимает прежние экспорты с массивом characters и массивы NPC. Проверяет весь файл до записи, показывает количество новых, совпадений и конфликтов, требует подтверждения. Импорт объединяет архивы: совпадающие ID с тем же содержимым пропускаются; конфликтующие ID не перезаписываются; старые записи без ID сравниваются по содержимому. Ограничения импорта: 20 МБ, 20 000 записей. Если хранилище переполнено, импорт не применяется. Не редактируйте экспорт вручную без резервной копии.

Архив хранится на конкретном устройстве и адресе сайта; не в GitHub. Автоматической синхронизации нет. Регулярно экспортируйте JSON; для переноса на другое устройство импортируйте его. При конфликте ID версия на принимающем устройстве сохраняется.

## Генерация

Базы идентификации, настроения, внешности и личности из v0.4 сохранены. Расы равновероятны 1/9, пол 1/2; светлые и тёмные эльфы 3:1. 12 настроений, 481 запись внешности, 500 записей личности. Фиксация аспектов личности работает как прежде. Service worker кэширует новый archive.js и обновлённые файлы.
