# Этерна — генератор NPC v0.2

Идентификация и внешность. Статическое PWA для iPad и браузера; без серверной части и внешних библиотек.

## Обновление существующего приложения v0.1

1. В прежнем приложении нажмите «Экспорт JSON» для резервной копии. Не удаляйте установленное приложение и не очищайте данные Safari.
2. Распакуйте архив. В существующем репозитории GitHub замените файлы в корне ветки `main` файлами новой версии (включая новый `appearance-data.js`, `sw.js` и `.nojekyll`). Не меняйте адрес Pages или путь размещения. Зафиксируйте изменения.
3. В разделе Actions/Pages проверьте успешную публикацию. Откройте прежний адрес с интернетом. Полностью закройте PWA и откройте снова; при необходимости повторите после обновления service worker. В заголовке должно появиться v0.2.
4. Проверьте старый архив, генерацию внешности и автономный запуск. Не очищайте данные сайта ради обновления — это может удалить архив.

Ключ localStorage сохранён (`eterna-npc-archive-v1`). Старые NPC открываются без внешности; кнопка «Вся внешность» добавляет её в текущую карточку. «Сохранить NPC» создаёт новую запись, не меняя прежнюю. Архив находится в хранилище конкретного браузера/установленного PWA, поэтому открывайте приложение тем же способом, на том же устройстве и адресе. Экспорт JSON — резервная копия; обратный импорт пока не предусмотрен.

## Первая установка

Создайте репозиторий (Public для бесплатного GitHub Pages; файлы и данные будут общедоступны), загрузите содержимое ZIP в корень `main`, включая `.nojekyll`. Settings → Pages → Deploy from a branch → main → /(root) → Save. Откройте адрес Pages на iPad в Safari → «Поделиться» → «На экран Домой» → «Открывать как веб-приложение» (если доступно). Первый запуск с сетью; дождитесь готовности автономного режима.

## Логика

- Исходные данные идентификации v0.1 сохранены: 12 853 имени, 4 777 фамилий, 30 занятий, исходные веса по контекстам. Независимый равновероятный выбор расы (1/9) и пола (1/2), затем выбор имени и фамилии.
- Источник внешности: `eterna-appearance-v0.25.xlsx`, 481 запись, включая внутреннюю таблицу типов эльфов. Светлый/тёмный — веса 3/1, то есть 75/25%. Все остальные записи и веса импортированы без изменений.
- Пять полей: видимый возраст, относительный рост и сложение, покров, характерная черта, отличительная примета. Одежды нет; пол не ограничивает внешность.
- Кнопка «Вся внешность» создаёт все пять полей заново и может сменить тип эльфа. Отдельная перегенерация не меняет тип и остальные поля. Смена расы создаёт новую внешность; смена пола, имени, фамилии или занятия её сохраняет. Полная генерация создаёт нового NPC.
- Копирование и архив включают внешность, если она есть. Сохранённые записи не меняются при последующей перегенерации.

## Файлы

`data.js` — идентификация; `appearance-data.js` — девять расовых профилей, категории, значения, веса и условия; `engine.js` — функции генерации; `app.js`, `index.html`, `style.css` — интерфейс и архив; `sw.js`, `manifest.webmanifest`, PNG — установка и автономная работа. При следующих обновлениях менять версию CACHE в sw.js. Встроенного импорта Excel нет.

## Проверки

Синтаксис JS проверен Node.js. Исходные данные идентификации сравнены с ZIP v0.1 (кроме номера версии совпадают). 9 000 расовых генераций с проверкой допустимости каждого поля и 45 000 отдельных перегенераций; 100 000 эльфов (75 205 светлых, 24 795 тёмных); 90 000 идентификаций. Логика интерфейса проверена в тестовой имитации DOM, включая старый архив, сохранение, копирование текста и фильтры. Реальный браузерный тест HTTP заблокирован средой; установка, обновление кэша, визуальное отображение и автономность требуют проверки на iPad. Сайт не опубликован автоматически.
