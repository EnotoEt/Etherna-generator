# Этерна — генератор NPC v0.4

Идентификация, настроение, внешность и личность. Статическое PWA для iPad и браузера; без сервера и внешних библиотек.

## Обновление v0.3

1. В прежнем приложении нажмите «Экспорт JSON» для резервной копии. Не удаляйте PWA и не очищайте данные Safari.
2. Распакуйте ZIP. Загрузите все файлы в корень того же репозитория GitHub (обычно ветка main), заменив старые, включая новый `mood-data.js`, изменённые `sw.js`, `engine.js`, `app.js`, `index.html`, `style.css`, `data.js` и `.nojekyll`. Не меняйте адрес Pages или путь размещения.
3. Проверьте успешную публикацию в Actions/Pages. Откройте прежний адрес с интернетом. Полностью закройте PWA и откройте снова; при необходимости повторите после обновления service worker. Заголовок должен показать v0.4.
4. Проверьте архив, генерацию, затем автономный запуск (в авиарежиме после готовности автономного режима).

Ключ localStorage прежний: `eterna-npc-archive-v1`. Старые NPC открываются с прежней идентификацией и внешностью (если была). Нажмите «Вся личность», чтобы добавить отсутствующий блок. «Сохранить NPC» создаёт новую запись, не переписывая старую. Архив локальный для конкретного браузера/PWA и адреса; экспорт JSON пока без обратного импорта.

## Новое в v0.4

- 12 настроений с согласованными весами (сумма 100). Проявление и возможное осложнение выбираются вместе с настроением, не независимо.
- Блок расположен сразу после идентификации. «Настроение ↻» обновляет только этот блок. Общая генерация создаёт новое настроение; отдельные генерации других модулей и фильтры сохраняют его.
- Старые NPC открываются без настроения, если его не было. Нажмите «Настроение», затем «Сохранить NPC» (создаётся новая запись). Копирование и экспорт включают настроение, когда оно есть.
- Веса можно редактировать в `mood-data.js`. Осложнения — подсказки мастеру, не автоматические штрафы.
- Кэш service worker обновлён до v0.4.0. Остальные базы и ключ архива сохранены.

## Функции v0.3 (сохранены)

- Пять обязательных аспектов: концепт, долгосрочная цель, краткосрочная цель, недостаток / проблема, свободный аспект.
- Источник: `eterna-personality-v0.3.xlsx`, 500 строк; по 100 на лист. ID, категория, значение и вес перенесены без изменений. Все аспекты универсальны; выбор независимый и взвешенный. В каждой таблице 50 записей веса 5, 40 веса 3, 10 веса 1 (65,79%, 31,58%, 2,63% соответственно).
- Общая генерация создаёт идентификацию, внешность и личность. «Вся идентификация» сохраняет личность и внешность при неизменной расе (при смене расы внешность генерируется заново). Отдельно доступны «Вся внешность», «Вся личность», перегенерация полей.
- «Закрепить» защищает аспект личности от случайной перегенерации, включая общую генерацию NPC; «Закреплено» снимает фиксацию. Фиксация — состояние текущего интерфейса; сбрасывается при открытии NPC из архива и перезапуске. «Изменить» → «Применить» сохраняет непустой пользовательский текст в текущей карточке, включая закреплённый аспект. Чтобы сохранить в архиве, нажмите «Сохранить NPC».
- Смена имени, фамилии, пола, профессии и расы не меняет личность. Копирование, сохранение, экспорт включают все имеющиеся блоки.
- Идентификация и внешность v0.2 не изменены: 12 853 имени, 4 777 фамилий, 30 занятий, 481 запись внешности; равновероятная раса 1/9, пол 1/2, светлые и тёмные эльфы 3:1.

## Первая установка

Создайте репозиторий (Public для бесплатного GitHub Pages; файлы и данные будут общедоступны), загрузите содержимое ZIP в корень main. Settings → Pages → Deploy from a branch → main → /(root) → Save. Откройте адрес Pages в Safari на iPad → «Поделиться» → «На экран Домой» → «Открывать как веб-приложение» (если доступно). Первый запуск с сетью.

## Файлы

`data.js` — идентификация; `appearance-data.js` — внешность; `personality-data.js` — личность; `mood-data.js` — настроение; `engine.js` — генерация; `app.js`, `index.html`, `style.css` — интерфейс и архив; `sw.js`, `manifest.webmanifest`, PNG — установка и автономная работа. Встроенного импорта Excel нет. При обновлениях менять версию CACHE в sw.js.

## Проверки v0.4

Node.js: синтаксис всех JS; 100 000 выборок настроения с проверкой связанных проявлений и осложнений и частот, 10 000 полных генераций. Chromium: исходные HTML/CSS/JS встроены в тестовую страницу (прямой переход к локальному файлу заблокирован); имитация буфера и хранилища. Проверены 12 последовательных перегенераций настроения без изменения иных полей, независимые генерации остальных блоков, копирование, сохранение, открытие старой записи, добавление настроения и экспорт JSON, отсутствие горизонтального переполнения при 390/820/1024 px. Реальный SW и установка на iPad не проверены. Публикация не выполнена.

HTTP заблокирован средой; реальный service worker, обновление кэша, системное хранилище, буфер обмена и установка на iPad требуют проверки после публикации. Сайт автоматически не опубликован.
